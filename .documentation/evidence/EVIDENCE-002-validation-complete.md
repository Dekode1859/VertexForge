```

```

## Key Design Decisions Validated

1. **Dynamic state creation** — `create_state_class()` builds TypedDict from JSON field definitions
2. **Tool registry** — String names in config resolved to real `@tool` callables via `TOOL_REGISTRY`
3. **ReAct agent factory** — `create_node_function()` chooses `create_react_agent` vs plain LLM based on tool list
4. **Structural validation** — `_validate_structure()` catches orphan nodes, missing entry points, duplicate IDs before compilation
